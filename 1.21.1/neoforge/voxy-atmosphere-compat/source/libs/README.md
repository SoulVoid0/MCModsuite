# Compile-only jars

Drop these here before building. They are other authors' mods: never committed, never bundled.

| File | What | Where |
|------|------|-------|
| `voxy.jar` | voxy-forged 1.1.0 (NeoForge 1.21.1) | build from https://github.com/falling-colud/voxy-forged (`./gradlew build`) or its release |
| `simpleclouds.jar` | Simple Clouds for NeoForge 1.21.1 (0.7.x) | CurseForge project 1121215 (Project Atmosphere 0.9.1.2 builds against file 6928979) |

The Simple Clouds API comes from the nonamecrackers2 maven automatically.
Project Atmosphere and Voxy SeedGen are not compile dependencies: they are detected at runtime.
