# Voxy Atmosphere Compat (NeoForge 1.21.1)

Compatibility patch for voxy-forged, Voxy SeedGen, Simple Clouds and Project Atmosphere. Each version has its own
folder with the jar and the source it was built from.

| Version | Jar | Notes |
|---|---|---|
| [1.6.0](1.6.0/) | `1.6.0/voxy-atmosphere-compat-1.6.0.jar` | Latest. Cloud height config (`cloudHeight`, default Y 1024; -1 = automatic) |
| [1.5.0](1.5.0/) | `1.5.0/voxy-atmosphere-compat-1.5.0.jar` | Fixes fragmented, see-through clouds with holes (cloud mesh overflow at large SeedGen distances) |
| [1.4.0](1.4.0/) | `1.4.0/voxy-atmosphere-compat-1.4.0.jar` | Cloud base kept above every nearby peak (no dark ragged cloud patches in mountains) |
| [1.3.0](1.3.0/) | `1.3.0/voxy-atmosphere-compat-1.3.0.jar` | Clouds hidden behind Voxy terrain with shaderpacks, rain shafts off |
| [1.2.0](1.2.0/) | `1.2.0/voxy-atmosphere-compat-1.2.0.jar` | Clouds lifted above the terrain (no more stripes/slabs in tall worlds) |
| [1.1.0](1.1.0/) | `1.1.0/voxy-atmosphere-compat-1.1.0.jar` | Soft far cloud edges, much more cloud coverage, stable `VoxyAtmoApi` |
| [1.0.0](1.0.0/) | `1.0.0/voxy-atmosphere-compat-1.0.0.jar` | First release |

Install one jar only (newest recommended).
