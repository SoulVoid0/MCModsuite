# Create: Long Haul Tracks (NeoForge 1.21.1)

Plans and builds Create train lines over very long distances, with tunnels, bridges and junctions. Each version has
its own folder with the jar and the source it was built from.

| Version | Jar | Notes |
|---|---|---|
| [1.4.0](1.4.0/) | `1.4.0/create-long-haul-tracks-1.4.0.jar` | Latest. Switchbacks for huge climbs instead of "Too steep" |
| [1.3.0](1.3.0/) | `1.3.0/create-long-haul-tracks-1.3.0.jar` | No more stalls on JJThunder (planning at 89%, building at 1%), real pause in single player |
| [1.2.0](1.2.0/) | `1.2.0/create-long-haul-tracks-1.2.0.jar` | Cancel planning, world freezes while the planner is open, ETAs |
| [1.1.0](1.1.0/) | `1.1.0/create-long-haul-tracks-1.1.0.jar` | Terrain-following route search, switchbacks/spirals, 1 track per 16 blocks, styles, clear-only mode |
| [1.0.0](1.0.0/) | `1.0.0/create-long-haul-tracks-1.0.0.jar` | First release |

Install one jar only (newest recommended). Works with any Voxy Atmosphere Compat version.
